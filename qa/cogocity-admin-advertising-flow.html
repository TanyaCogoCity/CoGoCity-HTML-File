Advertising

Manage Banner 1, Banner 2, and Banner 3 for desktop and mobile homepage placements.

How Admin Adds an Ad

  1. Open Admin → Advertising.
  2. Choose Banner 1, 2, or 3.
  3. Enter advertiser name and landing page URL.
  4. Upload a desktop image, recommended 300×250.
  5. Upload a mobile image, recommended 320×120.
  6. Enter CTA button text, such as Learn More or Register Now.
  7. Set expiration date and turn Active on.
  8. Click Replace Ad or Save Slot.
